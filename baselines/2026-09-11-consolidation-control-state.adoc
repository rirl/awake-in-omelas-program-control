== GitHub Tooling Boundary

GitHub API and automation authentication remains intentionally separate from direct Git repository operations.

The intended boundary is:

* `gh` uses its own OAuth authentication for GitHub API and automation operations;
* `git clone`, `git pull`, and `git push` use SSH;
* existing SSH Git configuration should not be altered merely to support `gh`;
* WSL2 `gh` authentication remains a separate decision from Git SSH access.

This boundary is part of the operating model and should be preserved unless explicitly reconsidered.
