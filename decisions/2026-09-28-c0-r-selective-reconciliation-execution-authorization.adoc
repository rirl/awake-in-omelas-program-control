== Semantic Execution Rules

For every assertion considered during execution:

* `RECONCILE` assertions may be represented in current canon.
* `PRESERVE-UNRESOLVED` assertions must remain visibly unresolved.
* assertions rejected as current canon must not be admitted as facts.
* historical wording is not authoritative merely because it appears in the
  recovery branch.
* historical file identity does not determine current semantic ownership.
* current representation should be the smallest representation consistent
  with the admitted execution proposal.
* existing controlled canon must not be rewritten merely to recreate the
  historical decomposition.

== Execution Method

Execution shall proceed as a working-tree construction.

The executor shall:

. verify all control preconditions;
. construct only the authorized eighteen-file set;
. derive content assertion-by-assertion from admitted dispositions;
. mark unresolved matters explicitly;
. construct the four reconciliation provenance records;
. compare the result with the controlled baseline and recovery evidence;
. verify rejected assertions are absent;
. verify historical-only tooling has not been restored;
. inspect the complete working-tree diff;
. perform cross-slice semantic validation;
. stop before staging or committing the canon changes.

== Mandatory Stop Conditions

Execution must stop without staging or committing if:

* the canon branch differs from the authorized branch;
* canon HEAD differs from the required baseline before construction;
* the canon working tree is not clean before construction;
* the recovery source cannot be resolved;
* an assertion cannot be classified under the admitted dispositions;
* an unresolved assertion would need to be converted into a fact;
* a rejected assertion would need to be admitted;
* execution requires a nineteenth file;
* execution requires modification of an existing file not explicitly
  authorized;
* historical tooling would need to be restored;
* a C1 architectural-responsibility decision would be required;
* the resulting cross-slice causal model conflicts with admitted constraints.

A stop condition requires review before execution continues.
